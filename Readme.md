# Linear Regression from Scratch

Небольшой учебный проект по реализации линейной регрессии с нуля с использованием градиентного спуска.

Цель проекта — не просто использовать готовую модель из `scikit-learn`, а разобраться в математике линейной регрессии и самостоятельно реализовать основные этапы обучения модели.

## Цель

В проекте реализованы:

* линейная регрессия для одного признака;
* функция предсказания;
* MSE (Mean Squared Error);
* вычисление градиентов;
* градиентный спуск;
* эксперимент с `learning rate`;
* масштабирование признака с помощью `StandardScaler`;
* сравнение собственной реализации с `sklearn.LinearRegression`.

## Датасет

Используется небольшой вручную созданный датасет с двумя признаками:

* `area` — площадь квартиры в м²;
* `price` — стоимость квартиры.

Всего используется 15 наблюдений.

Целевая зависимость:

$$
\hat{y} = wx + b
$$

где:

* `x` — площадь квартиры;
* `w` — коэффициент модели;
* `b` — смещение;
* `ŷ` — предсказанная стоимость.

## Математика

### Mean Squared Error

В качестве функции потерь используется среднеквадратичная ошибка:

$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y_i})^2
$$

Квадрат ошибки позволяет избежать взаимного сокращения положительных и отрицательных ошибок и сильнее штрафует большие ошибки.

### Градиенты

Для параметров `w` и `b`:

$$
\frac{\partial MSE}{\partial w}
=
-\frac{2}{n}\sum_{i=1}^{n}x_i(y_i-\hat{y_i})
$$

$$
\frac{\partial MSE}{\partial b}
=
-\frac{2}{n}\sum_{i=1}^{n}(y_i-\hat{y_i})
$$

### Градиентный спуск

Параметры обновляются по правилу:

$$
w := w-\alpha\frac{\partial MSE}{\partial w}
$$

$$
b := b-\alpha\frac{\partial MSE}{\partial b}
$$

где `α` — `learning rate`.

## Реализация

Основные функции реализованы самостоятельно:

```python
def predict(x, w, b):
    return w * x + b
```

```python
def mse(y_true, y_pred):
    return np.mean((y_true - y_pred) ** 2)
```

```python
def gradients(x, y, w, b):
    predictions = predict(x, w, b)
    errors = y - predictions

    dw = -2 * np.mean(x * errors)
    db = -2 * np.mean(errors)

    return dw, db
```

Обучение модели выполняется с помощью собственного цикла градиентного спуска.

## Эксперименты

### Влияние learning rate

При использовании исходного масштаба признака было проверено несколько значений `learning rate`.

| Learning rate | MSE после 100 итераций | Результат                          |
| ------------: | ---------------------: | ---------------------------------- |
|     `0.00001` |              ≈ 7478.91 | слишком медленное обучение         |
|      `0.0001` |              ≈ 7475.89 | улучшение, но медленная сходимость |
|       `0.001` | очень большое значение | обучение расходится                |

Эксперимент показывает, что слишком маленький шаг приводит к медленной сходимости, а слишком большой может привести к расходимости градиентного спуска.

### Масштабирование признака

Для эксперимента площадь квартиры была стандартизирована с помощью `StandardScaler`.

После масштабирования удалось использовать значительно больший `learning rate`:

```text
learning_rate = 0.1
iterations = 100
```

Результат:

```text
MSE ≈ 6669.84
```

Это практически совпало с результатом `LinearRegression` из `scikit-learn`.

Масштабирование не меняет качество самой линейной зависимости, но делает оптимизацию градиентным спуском более удобной.

## Сравнение со scikit-learn

Для проверки результата использовалась готовая реализация:

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)
```

Результат:

```text
w = 101.5714
b = -88.8095
MSE = 6669.84
```

Собственная реализация после масштабирования достигла практически такого же значения MSE.

Важно: `LinearRegression` из `scikit-learn` не подбирает `learning rate` для градиентного спуска. В данном случае модель решает задачу обычных наименьших квадратов численными методами.

## Выводы

В ходе проекта были практически проверены следующие идеи:

* линейная регрессия представляет зависимость целевой переменной от признаков через линейную функцию;
* MSE используется для измерения ошибки модели;
* градиент показывает направление наибольшего роста функции потерь, поэтому при градиентном спуске движение происходит в противоположную сторону;
* `learning rate` сильно влияет на скорость и стабильность обучения;
* слишком маленький `learning rate` замедляет обучение, слишком большой может привести к расходимости;
* масштабирование признаков может значительно улучшить работу градиентного спуска;
* собственную реализацию можно проверить сравнением с готовой реализацией `scikit-learn`.
